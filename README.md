# AppHub

Painel pessoal para acompanhar os apps: lista com status (laranja = pendências, verde = em ordem), tarefas por app (inclusive por voz) e botão de divulgação (endereço, descrição e hashtags para YouTube, Facebook, Instagram e TikTok).

- `index.html`: o painel (arquivo único). A lista de apps fica no começo do script (`APPS`).
- `dados.json`: números do Google Analytics por app. Vazio até a conexão automática ser ligada.
- As tarefas e os textos de divulgação ficam salvos no navegador do aparelho (não sincronizam entre aparelhos).
